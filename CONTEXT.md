# Yurucamp Domain Glossary & Vocabulary

This document defines the canonical domain vocabulary for Yurucamp Indonesia.

## Domain Concepts

### Camp Area (Lokasi Perkemahan)
A physical campsite location with amenities, capacity details, rules, and images. Managed by admins and browsable by users.

### Activity (Kegiatan / Outdoor Activity)
An outdoor activity or blog post highlighting outdoor experiences (e.g. camping tips, hiking, gear recommendations).

### Media Asset (Aset Media)
Digital images or files associated with domain entities (Camp Area photos, Activity headers, User Avatars).

### Image Processing Seam (`ImageUploadManager`)
The deep client-side module responsible for processing, compressing, signature authenticating, and uploading Media Assets to cloud storage (Cloudinary).

### Session & Identity
User authentication tokens and profile session states.
